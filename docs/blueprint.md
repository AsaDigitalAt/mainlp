# **App Name**: AsaFood AI Analyzer

## Core Features:

- Simplified Data Upload: Allows users to upload a screenshot of their iFood analytics dashboard.
- AI-Powered Data Processing: Uses AI to analyze uploaded screenshots, processing financial and operational metrics, and cross-referencing with high-performance benchmarks.
- Actionable Diagnostic Report: Generates a diagnostic report providing tailored recommendations for pricing adjustments and funnel optimizations, including clear actions to mitigate losses and improve profitability.
- Price Calculator: Tool to calculates prices based on various restaurant costs to reach the profit target.
- Menu Analysis: Tool powered by AI to help to find out errors and opportunities to improve your menu and find opportunities to sell more.
- Interactive Dashboard: Displays the processed analytics and actionable insights in an easy-to-understand visual format.
- Subscription Plans: Manages the available subscription plans

## Style Guidelines:

- Primary color: Deep red (#EA1D2C), used sparingly to create energy, grabbing attention in the user interface.
- Background color: Light tan (#fff4e2), lending a feeling of off-white/lightness to the UI
- Accent color: Cyan (#7aced8) as a refreshing call-out and highlight color against the dominant hues, for example, on badges.
- Body and headline font: 'Inter', sans-serif, as the workhorse of all UI text
- Use consistent, professional icons from Lucide library related to data analysis and restaurant management, with the red/cyan kept for accenting purposes.
- A clean and structured layout with clear sectioning and consistent spacing is used throughout the platform
- Subtle fade-in animations when content scrolls into view.
